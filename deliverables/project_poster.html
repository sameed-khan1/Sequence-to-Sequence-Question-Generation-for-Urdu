Task Formulation & Constraints

Goal: Given an Urdu sentence with an answer span marked by <ans> ... </ans>, generate a coherent, answerable interrogative question.

  • From Scratch Constraint: No Transformers, no Hugging Face Seq2Seq models, and no pretrained embeddings. Built purely from nn.LSTM, nn.Linear, and nn.Embedding primitives.
  • Sentence-Level Grounding: Following Du et al. (2017), using the answer-bearing sentence rather than 300-word paragraphs prevents recurrent gradient vanishing.

SentencePiece Subword Tokenizer

Trained an 8,000-subword Unigram model. Decomposes complex Urdu inflections into roots and suffixes:

  • پڑھا → پڑھ (stem) + ا (masculine aspect)
  • فرانسیسیوں → فرانس (France) + یسی (demonym) + وں (plural)
  • 10ویں → 10 + ویں (ordinal suffix)

Special tokens registered: <pad>=0, <unk>=1, <s>=2, </s>=3, <ans>=4, </ans>=5.

4

Architecture: Deep Seq2Seq + Attention

  • BiLSTM Encoder: 2 layers, 256-d embedding, 512-d hidden state per direction (1024-d combined). Uses pack_padded_sequence to prevent zero-padding traversal in backward pass.
  • Hidden State Bridging: 4 dedicated linear layers (bridge_h0, bridge_h1, bridge_c0, bridge_c1) project bidirectional states without layer collapse.
  • Bahdanau Additive Attention: \(e_{ti} = v^T anh(W_e h_i + W_d s_t)\) with explicit -inf pad masking.
  • Input Feeding: Previous context \(c_{t-1}\) concatenated with current token embedding before recurrence.

Search Dynamics: Beam Search & Blocking

Degenerative Loop Elimination: Naive decoding produces loops like کے ساتھ ساتھ ساتھ. We engineered:

  • Beam Search (\(k=3\)): Length penalty \(lpha = 0.7\) prevents shallow hypotheses.
  • Trigram Blocking: Dynamically sets logits to \(-\infty\) if a token creates an identical trigram, eliminating repetitive loops.
